# CLAUDE.md & AGENT GUIDELINES - Mikrotek Business Suite Neo

## Mandatory Workflow & Style Rules
- **Efficient Communication**: Always operate in Caveman Mode (ultra-compressed, direct, zero fluff).
- **Environment**:
  - PHP Binary: `/opt/homebrew/bin/php`
  - Run Tests: `/opt/homebrew/bin/php artisan test`
- **Build Flow**:
  - Development phase: `npm run dev`
  - Done / Finished phase: `npm run build`
- **Version Tracking**:
  - Update `CHANGELOG.md` for any new feature, bug fix, or schema change. Increment version following semver (`v1.x.x`).
